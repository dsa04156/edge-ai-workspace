# 그림 설명

"
        "- `p95-ttft`: 동시성 증가에 따른 p95 TTFT. 회색 점선은 1,500ms SLO다.
"
        "- `throughput`: 동시성 증가에 따른 완료 요청 처리량이다.
"
        "- `p95-latency`: 동시성 증가에 따른 전체 요청 p95 지연시간이다.
"
        "- `p95-queue`: 동시성 증가에 따른 관측 queue length p95다.

"
        "색상에만 의존하지 않도록 marker와 선 모양을 함께 사용했다. 정확한 수치는 "
        "상위 폴더의 `saturation-summary.csv`에서 확인한다.
