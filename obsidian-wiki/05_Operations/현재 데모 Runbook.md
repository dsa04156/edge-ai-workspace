# 현재 데모 Runbook

현재 데모 runbook은 [[현재 데모 경로]]를 기준으로 운영 절차를 정리한다.

## 확인 순서

1. edge node 상태 확인
2. mapper Pod 상태 확인
3. MQTT publisher 실행 위치 확인
4. InfluxDB latest telemetry 확인
5. state-aggregator API 확인
6. dashboard 표시 확인
