# 대시보드 정책

대시보드는 DB latest timestamp와 [[DeviceStatus 정책]] snapshot freshness를 분리해서 표시한다.

## 핵심 원칙

- `status.state=online`만으로 healthy 처리하지 않는다.
- healthy 판단은 InfluxDB latest timestamp를 우선 기준으로 삼는다.
- DeviceStatus timestamp와 `health=ok`는 운영 snapshot 해석용 보조 정보다.
- DB latest timestamp가 없으면 DeviceStatus만으로 healthy 근거를 만들지 않는다.

## 상태 판단 요약

1. Kubernetes `Device`와 `DeviceStatus` 목록을 조회한다.
2. 노드 미할당 또는 할당 노드 unavailable이면 `unavailable`.
3. `mqttvirtual` 디바이스인데 mapper Pod가 Running이 아니면 `unavailable`.
4. 명시적 offline/failed/unavailable 상태면 `unavailable`.
5. InfluxDB latest timestamp가 fresh하면 `healthy` 후보가 된다.
6. DB timestamp가 없거나 stale이면 `degraded`.
7. DeviceStatus freshness는 별도 표시한다.
