# 현재 데모 경로

현재 데모 운영 경로는 `state-aggregator` 중심으로 단순화한다.

```text
Device / DeviceStatus
MQTT telemetry
InfluxDB latest telemetry
Prometheus metrics
state-aggregator API
dashboard
```

과거 워크플로우 실행/배치 실험 컴포넌트는 현행 대시보드와 데모 운영 경로에서 제외한다. 관련 문서는 [[아카이브 MOC]]에서 추적한다.
