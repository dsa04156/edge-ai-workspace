# 디바이스-서비스 연결 구조

디바이스-서비스 연결 구조는 현재 PoC의 핵심 설명 축이다. 운영자는 어떤 서비스가 어떤 디바이스와 노드에 연결되어 있고, 해당 연결이 정상인지 대시보드에서 확인할 수 있어야 한다.

## 바인딩이 설명해야 하는 것

- 서비스 이름
- 연결된 디바이스 이름
- 디바이스가 할당된 edge node
- mapper 실행 상태
- telemetry freshness
- DeviceStatus snapshot freshness
- 서비스 관점의 영향도
