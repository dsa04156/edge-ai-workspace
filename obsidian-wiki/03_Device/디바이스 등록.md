# 디바이스 등록

현재 데모 단계는 사전 등록 방식이다.

## 절차

1. `DeviceModel`과 `Device` CR을 Kubernetes에 미리 등록한다.
2. 각 `Device`는 특정 edge node의 `spec.nodeName`에 바인딩한다.
3. mapper는 edgecore/DMI를 통해 해당 `Device`를 전달받는다.
4. 센서 수집 프로그램 또는 테스트 publisher는 [[MQTT Topic 규칙]]에 맞춰 MQTT payload를 발행한다.

## 노드 배치

- Jetson: `etri-dev0001-jetorn`
- Raspberry Pi 5: `etri-dev0002-raspi5`

> [!warning]
> 센서가 MQTT로 임의 topic에 publish한다고 자동으로 KubeEdge `Device`가 생기지는 않는다.
