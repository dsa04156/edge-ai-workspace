# 전체 노드 · 서비스 배치 가시화 검증

2026-09-14 사용자가 전체 AI 서비스 자동 배치 설계의 정보를 먼저 대시보드에 표시하도록 요청했다.
기존 OFFLOAD DEMO에서 서비스 선택 → 운영 제어 → 전체 노드 · 실행 후보 → 요청 진단 순서로 표시한다.

## 반영한 범위

- 기존 runtime gateway 관측에서 허용된 모델·입력 종류·공통 자원 선언·기본/후보 노드만 요약한다.
  입력 본문, worker endpoint와 임의 중첩 필드는 공개하지 않는다. 기존 GET API를 확장했다.
- `/state/nodes`, `/api/resources`와 서비스 후보 결과를 합쳐 전체 10개 노드를 표시했다.
- Llama 등록·연결 후보 3개, 다른 AI 서비스의 공통 제어 미연결 상태를 확인했다.
- 총 할당 가능량, Pod 요청 예약량, 예약 차감 잔량을 실측 CPU·메모리·GPU·온도와 구분한다.
- 정지 중인 서비스는 재평가 대기, 오래된 관측은 판단 불가다. 과거 제외 근거는 과거라고 표시한다.
- 한 노드의 실행 형태 하나가 통과하면 다른 형태가 제외됐다는 이유만으로 노드 전체를 제외하지 않는다.
- 필터·노드 상세만 추가했고 서비스 실행·부하 버튼·자동 배치 정책은 변경하지 않았다.

## 검증

- JavaScript 관련 32개, Python projection/읽기 API 관련 15개 검사 통과.
- 미연결 성능 표시의 시각 보정 후 관련 JavaScript 6개 재검사 통과.
- 실제 페이지에서 전체10개 → 등록후보3개 필터, 노드 상세, 5초 갱신 후 상세 유지 확인.
- 다른 AI 서비스로 전환 시 Llama 모델 정보가 섞이지 않으며, 복귀 시 필터가 유지된다.
- 1440×1100 및390×844 화면을 확인했고 페이지 가로 넘침 없이 표 내부 가로 스크롤을 확인했다.
- 브라우저 console 오류0건. 모델 준비·부하를 실제로 만들지 않고 화면 상태와 읽기 API만 확인했다.
- 배포 이미지 변경5파일의 Ready Pod 해시가 빌드 입력과 일치하고 Argo Synced/Healthy 확인.
- 확인 시 활성시험0, Llama Suspended. 기존 브랜치에 반영했으며 새 브랜치를 생성하지 않았다.

## 남은 연결

노드별 이미지·자원 요구량 상세, 검증 입력 조건·측정 시각, 실제 입력/시험 입력별 유입량 분리는
아직 이 화면에 연결되지 않았다. 범용 후보 선택과 다중 서비스 예약 조정은 설계 후속 범위다.
후보 표가 전체 노드에서 모든 AI 모델의 실행을 검증하거나 자동 배포한 것으로 해석하지 않는다.
이미지와 실제 관측 근거는 images.json, verification.json을 따른다. 시각 검사 이미지는 /tmp에서 검토했다.
