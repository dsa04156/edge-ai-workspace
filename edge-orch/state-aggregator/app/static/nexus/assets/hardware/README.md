# 서비스 구성도 장비 이미지

2026-09-10, built-in imagegen으로 생성한 유형별 예시 이미지다. 실제 설치 장비 사진이나 모델·사양의 증거가 아니다. 서비스 이름, Pod, 상태 및 연결은 HTML/SVG로 별도 표시한다.

최종 파일: `jetson.png`, `raspberry-pi.png`, `server.png` (1254×1254 RGBA PNG). 세 파일 모두 투명 배경이며 생성 원본을 그대로 복사했다. 미등록 노드는 장비 유형을 추정하지 않고 일반 노드 아이콘을 쓴다.
