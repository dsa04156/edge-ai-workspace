## 배포 소유권

| 대상 | Argo CD Application | 기준 ref |
|---|---|---|
| 중앙 EdgeX·Device Service | `edgex-telemetry` | `main`의 `edgex/k8s` |
| 대시보드 | `edge-orch-state-aggregator` | Application에 선언된 Git ref |
| 문서 사이트 | `docs-html` | `main` + image updater digest |

live 리소스를 직접 수정해 Git과 충돌시키지 않는다. image를 바꾸면 tag가 아니라 registry에서
확인한 immutable digest와 실제 Pod `imageID`까지 검증한다.

## 문서 구조

`docs/`에는 공개 문서와 내부 이력이 함께 있지만 `scripts/build-docs-html.py`는 공개 목록만
생성한다. `docs/html/`과 검색 색인은 생성물이므로 직접 편집하지 않는다.
