# 중앙 MessageBus 직접 수집 재구축 절차 — 폐기

## 상태

이 문서는 더 이상 실행 가능한 운영 절차가 아니다.

과거 `telemetry` namespace의 범용 Device Service 재구축 절차와 이후 custom Agent/HTTPS topology는 모두 폐기됐다. 현재 `edgex-edge`의 좁은 Serial Device Service도 중앙 MessageBus를 사용하지만 root Kustomize로만 관리한다. 이 파일의 예전 명령으로 namespace, Deployment 또는 PVC를 재구축하면 현재 구성을 손상시킬 수 있다.

## 현재 진입점

- 배포: `edgex/k8s/kustomization.yaml`
- 운영 점검: [현재 서비스 데모 운영 절차](현재-데모-운영-절차.md)
- 아키텍처: [원시 텔레메트리 데이터 플레인](../원시-텔레메트리-데이터-플레인.md)

현재 경로:

```text
physical endpoint
  -> device-serial-jetson
  -> EdgeX Event / Reading
  -> central internal MessageBus
  -> EdgeX Core Data / PostgreSQL
```

현재 `device-serial-jetson`이 배포되어 있다. 중앙 `edgex-messagebus`는 stock EdgeX Core 내부 런타임용 ClusterIP이며 Device Service는 EdgeMesh DNS의 FQDN으로 접근한다. 고정 IP나 과거 범용 topology를 복구하지 않는다.

## 파괴적 재설치

데이터 삭제, namespace 재생성 또는 PVC 제거가 필요하면 대상 namespace, 보존할 shared workload, Secret 재발급, image digest와 복구 검증을 별도 작업 문서로 먼저 승인한다. 이 폐기 문서는 그 권한이나 절차를 제공하지 않는다.

과거 전환 기록은 `docs/archive/integration/`에서 비교 근거로만 확인한다.
