# 일일 기록

> 상태: 설계 이력. 현재 운영 기능의 완료 근거가 아니며 작업·검증 이력으로 보존한다.

## 목적

이 문서는 KubeEdge 기반 혼합 디바이스 edge AI 운영 가시화 PoC의 일일 작업 기록을 남기기 위한 문서다.

일지는 매일의 작업 사실, 확인한 상태, 남은 이슈, 다음 작업을 짧게 기록하는 용도다.
현재 PoC는 서비스 데모 우선, 디바이스-서비스 연결 구조, 통합 운영 가시화, 현장 적용성, 생산성 향상 효과를 중심으로 설명한다.

## 작성 원칙

- 실제로 확인한 내용과 계획을 구분한다.
- dashboard에서 관찰한 상태는 telemetry freshness, DeviceStatus snapshot, mapper 상태, node 상태를 나눠 적는다.
- `status.state=online`만으로 healthy라고 판단하지 않는다.
- raw telemetry 값을 DeviceStatus에 올린 것처럼 쓰지 않는다.
- workflow/offloading/agent-assisted planning은 현재 구현 완료 기능처럼 쓰지 않는다.
- 이슈는 원인 확정 여부를 함께 적는다.
