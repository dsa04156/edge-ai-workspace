# 카젠티 운영 보조 에이전트 PoC

> **현재 전환 상태:** 2026-07-21 custom edge Agent와 `sensehat-001` bootstrap이 퇴역했다. 이 문서의 해당 device payload와 점검 문구는 응답 형식 예시이며 live device 증거가 아니다. 새 Device Service가 배포되기 전 assistant는 "등록 device 없음/telemetry 전환 중"을 그대로 보고해야 한다.

## 목적

Kagenti operator assistant는 EdgeX-backed `state-aggregator` API를 read-only로 조회해 한국어 운영 요약과 점검 순서를 제안한다. 자율 제어, 자동 복구 또는 배치 계층이 아니다.

```text
EdgeX state -> state-aggregator -> read-only operator summary -> human operator
```

물리 디바이스 정보의 권위는 EdgeX Core Metadata와 Core Data다.

## 현재 endpoint

```text
GET /state/operator-assistant
```

참조 API:

```text
/state/dashboard
/state/devices
/state/nodes
/state/summary
/state/virtual-resources
```

`/state/nodes`와 resource 정보는 workload 진단용이다. 물리 device availability 판단에는 사용하지 않는다.

## 응답 구조

| field | 의미 |
|---|---|
| `generated_at` | 요약 생성 시각 |
| `assistant_name` | PoC assistant 이름 |
| `mode` | `read_only` |
| `summary_ko` | Core Metadata 등록·available 수와 Core Data freshness 요약 |
| `focus_devices[]` | degraded/unavailable device 중 우선 확인 대상 |
| `recommended_actions[]` | 사람이 수행할 점검 순서 제안 |
| `guardrails[]` | mutation 금지 경계 |
| `source_endpoints[]` | 요약에 사용한 read-only API |

## `/state/devices`에서 읽는 계약

Assistant와 dashboard는 다음 EdgeX-backed 필드를 사용한다.

```text
name
source
profile_name
device_service_name
protocol_names
admin_state
operating_state
connection_state
device_service_available
latest_event_timestamp
latest_readings[]
telemetry_freshness
node_name
```

`source=edgex`이며, profile/논리 수집 서비스/protocol/admin/operating 정보는 Core Metadata에서 온다. Event timestamp, `source_name`, `resource_name`, value는 Core Data에서 온다. `node_name`은 선택적 진단 정보다.

## 운영자 요약 예시

```text
EdgeX 기반 read-only 운영 보조 요약입니다.
Core Metadata 등록 device 1개 중 available device 1개,
우선 점검 대상 0개입니다.
Core Data event freshness 비율은 1.0입니다.
```

수치 예시는 payload 형식 설명용이며 live 환경의 현재 수치를 주장하지 않는다.

## Focus device 예시

```json
{
  "name": "sensehat-001",
  "node_name": null,
  "status": "degraded",
  "reason": "Edge telemetry agent is UP but latest Core Data event is stale",
  "admin_state": "UNLOCKED",
  "operating_state": "UP",
  "device_service_available": true,
  "telemetry_freshness": "stale"
}
```

Focus payload는 `/state/devices` 계약의 운영 판단 필드만 요약한다. 상세 조사에서는 원본 항목의 `source`, profile, 논리 수집 서비스, protocol, `latest_event_timestamp`, `latest_readings`를 함께 확인한다.

## Recommended action 예시

```text
sensehat-001: I2C adapter, edge outbox, HTTPS gateway와 Core Data 최신 event를 순서대로 확인한다.
```

추천 규칙:

- `admin_state=LOCKED`: Core Metadata admin 정책을 확인한다.
- `operating_state`가 UP이 아니거나 `device_service_available=false`: 논리 수집 서비스 등록, agent health와 physical adapter connection을 확인한다.
- `telemetry_freshness`가 fresh가 아님: Core Data 최신 event, profile resource, event source를 확인한다.
- 필요할 때에만 node/workload placement를 별도 진단한다.

Agent는 점검 순서를 제안할 뿐 명령을 실행하지 않는다.

## 서비스 영향 설명

Assistant가 설명하는 binding은 다음 흐름이다.

```text
EdgeX Device
  -> Protocol Adapter -> edge telemetry agent / SQLite outbox
  -> HTTPS ingest gateway -> Core Data / PostgreSQL
  -> AI service / storage / dashboard
```

운영자는 profile, protocol, 논리 수집 서비스, adapter/agent 상태와 Core Data source/resource를 통해 어느 consumer가 영향을 받는지 확인한다. 이 관계는 workflow orchestration이나 자동 placement가 아니다.

## Guardrail

금지 범위:

- EdgeX Core Metadata device/profile 수정
- Protocol Adapter 또는 telemetry agent 재시작·재배포
- MQTT 또는 다른 protocol command 발행
- Kubernetes 리소스 생성·수정·삭제
- actuator 직접 제어
- 자동 placement/offloading/workflow 실행
- LLM 기반 전역 제어

허용 범위:

- state-aggregator read-only API 조회
- EdgeX KPI와 device 상태 요약
- degraded/unavailable device 목록화
- Core Data event freshness와 latest readings 설명
- runbook 기반 점검 순서 제안
- AI/storage/dashboard consumer 영향 범위 설명

Workflow designer와 assistant preview는 dry-run/no-mutation 경계를 유지한다.

## 현재 physical 범위

2026-07-21 현재 기존 loopback Agent/SQLite/HTTPS edge 경로와 `sensehat-001` bootstrap은 퇴역했고 edge Device Service는 아직 없다. assistant는 중앙 EdgeX가 Running이라는 사실을 physical device 연결 완료로 요약하지 않는다. 다음 Jetson Serial Device Service와 이후 MQTT-only·Modbus·OPC-UA·I2C/RTSP wave는 profile, 실제 endpoint, Core Data Event와 consumer 처리를 각각 검증한 뒤에만 활성 상태로 보고한다.

## 생산성 표현

```text
Kagenti operator assistant는 EdgeX 기반 device identity, 논리 수집 서비스 상태와 Core Data event freshness를 read-only로 요약한다. 운영자는 전체 장치를 개별 명령으로 확인하기 전에 focus list와 추천 점검 순서로 문제 범위를 좁히고, source/resource별 최신 reading과 AI·저장소·dashboard 영향 범위를 확인할 수 있다.
```

이는 운영 점검 경로를 단순화하는 PoC 언어다. 자동 복구, live deployment 완료, 정량적 인력 절감 또는 미구현 protocol 지원을 주장하지 않는다.
