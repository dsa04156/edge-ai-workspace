## 보관 문서

`docs/archive/`는 과거 통합 기록, 연구 초안, legacy orchestration 자료다. 보관 문서에는 HTML에서 과거 자료 안내가 표시되며, 현재 기준 문서로 이동하는 링크를 우선한다. 원본은 삭제하지 않고 역사·재현 근거로 보존한다.

- `archive/integration/`: 과거 통합·인수인계·MQTT canary 기록
- `archive/legacy-orchestration/`: 과거 오케스트레이션·placement·offloading 설명
- `archive/embedded-conference/`: 선택적 재계획 관련 과거 실험
- `archive/research/`: 논문·평가·연구 전략 초안

보관 문서의 내용을 현재 운영 구조로 승격하려면 먼저 `프로젝트-범위.md`와 `저장소-구조.md`에 범위·소유권·검증 기준을 추가해야 한다.

## 생성물과 검증

- 원본: `docs/**/*.md`
- 생성물: `docs/html/`
- 생성기: `scripts/build-docs-html.py`
- 검색 색인: `docs/html/search-index.json`
- 문서 정합성 보고서: `tools/docs_consistency/generate_report.py`

HTML 생성과 정합성 검사는 로컬 checkout 기준이다. 라이브 문서 웹 반영은 별도 배포 작업과 URL 확인이 필요하다.
