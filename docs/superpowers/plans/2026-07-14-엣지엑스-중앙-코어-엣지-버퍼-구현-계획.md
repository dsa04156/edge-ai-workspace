# 엣지엑스 중앙 코어와 엣지 버퍼 구현 계획

> **상태: 이력 보존 / 그대로 실행 금지.** 이 계획의 “모든 source가 local MQTT를 사용한다”는 전제와 파일 경로 일부는 폐기됐다. 현재 승인 설계와 구현 상태는 `../specs/2026-07-14-엣지엑스-중앙-코어-엣지-버퍼-설계.md`, `../../원시-텔레메트리-데이터-플레인.md`, root `edgex/k8s/kustomization.yaml`을 따른다. 현재 기본 source는 direct loopback이고 MQTT는 optional compatibility mode다.

> 분류: 설계 이력. 현재 운영 기능의 완료 근거가 아니다.

**Goal:** 센서가 연결된 KubeEdge 노드에는 MQTT 수집·SQLite 임시 버퍼 agent 한 개만 두고, `etri-ser0002-cgnmsb`의 EdgeX Core Data와 PostgreSQL에 저장 확인 기반으로 telemetry를 통합 보관하는 MQTT 수직 슬라이스를 구현한다.

**Architecture:** 로컬 Mosquitto를 구독하는 ARM64 edge agent가 EdgeX Event UUID를 생성하고 SQLite outbox에 먼저 commit한 뒤 HTTPS ingest gateway로 전송한다. amd64 중앙 gateway는 제한된 `POST /v1/events`만 제공하고 EdgeX Core Data 4.0.2의 Add Event API 결과와 ID 조회를 이용해 PostgreSQL 저장 또는 동일 Event 재전송을 확인한다. 기존 Jetson 전체 EdgeX stack은 canary 전환이 끝날 때까지 그대로 보존한다.

**Tech Stack:** Python 3.12, paho-mqtt 2.x, PyYAML 6.x, SQLite WAL, Python standard-library HTTP/TLS, pytest 8.x, EdgeX Foundry 4.0.2, PostgreSQL 16.3, Kubernetes/KubeEdge, Kustomize, Argo CD, Kaniko, private registry `192.168.0.56:5000`.

## Global Constraints

- 모든 repository shell command는 `rtk`로 시작한다.
- EdgeX release는 `4.0.2`로 고정한다. amd64 image는
  `edgexfoundry/core-keeper:4.0.2`,
  `edgexfoundry/core-common-config-bootstrapper:4.0.2`,
  `edgexfoundry/core-data:4.0.2`,
  `edgexfoundry/core-metadata:4.0.2`를 사용한다.
- 중앙 workload는 `etri-ser0002-cgnmsb`(`amd64`, InternalIP `192.168.0.5`)에만 배치한다.
- edge agent는 `edgeai.etrilab/sensor-gateway=true`인 ARM64 EdgeCore 노드에만 배치한다.
- 현재 source adapter는 MQTT 하나이며 입력 topic은 `factory/devices/{device-name}/telemetry`다.
- Modbus, OPC-UA와 RTSP adapter 및 actuator command는 이번 수직 슬라이스에 포함하지 않는다. RTSP frame은 이 outbox에 넣지 않는다.
- outbox 경로는 `/var/lib/edge-telemetry-buffer/outbox.db`, 기본 한도는 24시간 또는 1GiB 중 먼저 도달한 조건이다.
- outbox record는 Core Data `201` 또는 동일 UUID의 저장 내용 확인 뒤에만 삭제한다. MQTT PUBACK은 삭제 근거가 아니다.
- Core Data `Writable.PersistData=true`를 manifest와 live write/read smoke 양쪽에서 검증한다.
- raw telemetry를 KubeEdge DeviceStatus에 기록하지 않고 KubeEdge Device/DeviceModel CRD를 변경하지 않는다.
- 외부 endpoint는 `https://192.168.0.5:30443/v1/events` 하나다. Core Data, Metadata, Keeper, MessageBus와 PostgreSQL은 ClusterIP다.
- TLS private key와 bearer token은 Git에 commit하지 않는다. live namespace에 사전 생성한 Secret을 mount한다.
- 기존 `telemetry` namespace의 Jetson EdgeX workload와 PVC는 삭제하지 않는다.
- image build tag는 `192.168.0.56:5000/edge-telemetry-agent:0.1.0`과 `192.168.0.56:5000/edgex-ingest-gateway:0.1.0`이고, Deployment에는 registry가 반환한 immutable digest를 사용한다.
- 구현은 TDD 순서로 진행하고 각 task가 통과할 때 별도 commit한다.

def test_enqueue_is_durable_before_upload(tmp_path, pending_event) -> None:
    path = tmp_path / "outbox.db"
    first = SQLiteOutbox(buffer_config(path))
    assert first.enqueue(pending_event) == 0
    first.close()

    reopened = SQLiteOutbox(buffer_config(path))
    assert reopened.next_ready(pending_event.queued_at_ns + 1).event_id == pending_event.event_id


def test_ack_is_the_only_normal_delete(tmp_path, pending_event) -> None:
    outbox = SQLiteOutbox(buffer_config(tmp_path / "outbox.db"))
    outbox.enqueue(pending_event)
    assert outbox.ack(pending_event.event_id) is True
    assert outbox.snapshot(pending_event.queued_at_ns + 1).pending_records == 0


def test_retry_applies_capped_exponential_backoff(tmp_path, pending_event) -> None:
    outbox = SQLiteOutbox(buffer_config(tmp_path / "outbox.db", retry_max=4))
    outbox.enqueue(pending_event)
    now = pending_event.queued_at_ns + 1
    outbox.retry(pending_event.event_id, "gateway_unavailable", now)
    assert outbox.next_ready(now + 999_999_999) is None
    assert outbox.next_ready(now + 1_000_000_000).attempt_count == 1


def test_terminal_record_moves_without_blocking_device_fifo(tmp_path, two_events) -> None:
    outbox = SQLiteOutbox(buffer_config(tmp_path / "outbox.db"))
    for event in two_events:
        outbox.enqueue(event)
    outbox.terminal(two_events[0].event_id, "dead_letter", "invalid_schema", 10)
    now = two_events[-1].queued_at_ns + 1
    assert outbox.next_ready(now).event_id == two_events[1].event_id
    assert outbox.snapshot(now).dead_letter_records == 1


def test_size_or_age_limit_drops_oldest_and_counts_it(tmp_path, three_events) -> None:
    outbox = SQLiteOutbox(buffer_config(tmp_path / "outbox.db", max_bytes=1))
    for event in three_events:
        outbox.enqueue(event)
    assert outbox.snapshot(three_events[-1].queued_at_ns + 1).dropped_records >= 1
