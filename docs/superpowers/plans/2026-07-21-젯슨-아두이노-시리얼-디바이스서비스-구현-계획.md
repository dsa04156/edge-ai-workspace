# Jetson Arduino Serial Device Service Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Jetson의 실제 Arduino Uno JSON line을 공식 EdgeX Go Device SDK로 수집해 Core Metadata, Core Data/PostgreSQL, Core Command GET과 대시보드까지 연결한다.

**Architecture:** `device-serial-jetson`은 Serial byte stream을 bounded line framer와 strict parser로 해석하고 SDK `AsyncValuesChannel`에 typed Reading을 전달한다. Device Service는 `edgex-edge`의 단일 privileged 예외 Pod로 Jetson의 stable Arduino char device만 mount하며, 중앙 Keeper/Metadata/MessageBus에는 EdgeMesh가 제공하는 Kubernetes FQDN으로만 연결한다.

**Tech Stack:** Go 1.25.x, EdgeX `device-sdk-go/v4 v4.0.2`, `go.bug.st/serial v1.8.0`, ko v0.19.1, Kubernetes/Kustomize, pytest, Argo CD

## Global Constraints

- Device Service/Profile/Device 이름은 각각 `device-serial-jetson`, `etri-arduino-serial`, `arduino-001`이다.
- Serial endpoint는 `/dev/serial/by-id/usb-Arduino__www.arduino.cc__0043_75035303230351E0D171-if00`, container path는 `/dev/arduino-001`, baud는 `115200`이다.
- Event source는 `temperature`, `light`, `magnetic`, `acceleration`; Reading은 `temperature_raw`, `light_raw`, `magnetic_raw`, `acceleration_x_raw`, `acceleration_y_raw`, `acceleration_z_raw`의 `Int32`다.
- Device Service만 `privileged: true` 예외를 가지며 exact node/device, `Recreate`, token 차단, read-only root filesystem, non-hostNetwork와 제한 NetworkPolicy를 동시에 적용한다.
- 중앙 연결은 `*.edgex-system.svc.cluster.local` FQDN만 사용하고 고정 ClusterIP, PodIP, node IP를 구성에 넣지 않는다.
- 기존 Agent, local MQTT broker, SQLite/PVC, KubeEdge Device/Mapper, EdgeMesh 설정은 추가·수정하지 않는다.
- write/actuator command, offline replay, local workflow API, 다른 protocol은 범위 밖이다.
- 구현 기준 문서는 `docs/superpowers/specs/2026-07-21-젯슨-아두이노-엣지엑스-시리얼-디바이스서비스-설계.md`다.

- [ ] **Step 3: strict parser 최소 구현을 작성한다**

```go
type Reading struct {
    ResourceName string
    Value        int32
}

type Sample struct {
    DeviceName string
    SourceName string
    Readings   []Reading
}

func ParseLine(line []byte, expectedDevice string) (Sample, error) {
    decoder := json.NewDecoder(bytes.NewReader(line))
    decoder.DisallowUnknownFields()
    decoder.UseNumber()
    var wire wireSample
    if err := decoder.Decode(&wire); err != nil { return Sample{}, fmt.Errorf("invalid serial JSON: %w", err) }
    if err := ensureEOF(decoder); err != nil { return Sample{}, err }
    if wire.DeviceID != expectedDevice { return Sample{}, fmt.Errorf("unexpected device_id %q", wire.DeviceID) }
    return wire.toSample()
}
```

`wireSample.toSample()`은 sensor별 허용 field 집합을 정확히 검사하고 `json.Number.Int64()`와 Int32 범위 검사를 통과한 값만 반환한다.
