## 권위 경로 한 장 요약

```text
물리 센서·PLC·장비
  -> 노드 로컬 EdgeX Device Service
  -> canonical EdgeX Event
  -> EdgeX Core Data / PostgreSQL
  -> state-aggregator / dashboard / AI consumer
```

- Device/Profile, admin/operating state의 권위는 중앙 EdgeX Core Metadata다.
- Event/Reading과 freshness의 권위는 중앙 EdgeX Core Data와 PostgreSQL이다.
- 노드·워크로드 배치의 권위는 Kubernetes/KubeEdge지만 physical availability를 대신 판단하지 않는다.
- 현재 Serial·I2C는 Device Service가 중앙 EdgeX로 직접 Event를 발행한다. MQTT-only 장비는 별도 검증 후 추가한다.
