## 위키 문서

- [운영 모델](운영-모델.md): 현재 PoC의 목표, 권위 경로, 완료 판단 기준을 요약한다.
- [현재 데모 흐름](현재-데모-흐름.md): Jetson Arduino Serial과 Raspberry Pi Sense HAT 직접 I2C Device Service부터 중앙 Core Data와 dashboard까지의 현재 수직 슬라이스를 정리한다.
- [상태와 텔레메트리](상태와-텔레메트리.md): EdgeX 물리 디바이스 상태·텔레메트리와 KubeEdge 노드·워크로드 상태를 분리한다.
- [대시보드와 KPI 모델](대시보드와-kpi.md): 디바이스·서비스·노드·KPI를 운영 판단 기준으로 묶는다.
- [운영 진입점](운영-진입점.md): 실제 데모 실행과 검증 문서로 안내한다.
- [2차년도 설계 트랙](2차년도-설계-트랙.md): 옥동 우선 서비스 2종과 월별 추진계획을 기술 설계·현재 완료 기능과 구분한다.
