# 원시 텔레메트리 데이터 플레인

## 핵심 계약

현재 Serial/I2C 데이터는 EdgeX Device Service가 물리 endpoint를 직접 읽고 EdgeX Event로
발행한다. EdgeX Core Data와 PostgreSQL이 장기 Event/Reading 권위다.

| 단계 | 책임 | 권위 |
|---|---|---|
| 물리 연결 | node-local Device Service | 장치 open, 재연결, protocol error |
| schema | EdgeX Device Profile | resource, type, units, read/write |
| inventory | EdgeX Core Metadata | Device, Profile, Device Service, 상태 |
| telemetry | EdgeX Core Data | Event, Reading, `origin` |
| edge inference 입력 | Device Service Local Data API | bounded recent cache, read-only |
| 파생 결과 | AI 서비스 저장소 | model result, alert, model version |
| 운영 조회 | `state-aggregator` | 권위 데이터를 결합한 read model |

## Event와 freshness

대시보드는 latest Event의 nanosecond `origin`을 sample 시각으로 사용한다. API 조회 시각,
Pod 시작 시각이나 Kubernetes node heartbeat로 sensor freshness를 대신하지 않는다.

```json
{
  "deviceName": "virtual-acceleration-x-001",
  "profileName": "etri-arduino-acceleration-x",
  "sourceName": "acceleration_x",
  "origin": 1784016000000000000,
  "readings": [
    {
      "resourceName": "acceleration_x_raw",
      "valueType": "Int32",
      "value": "512",
      "origin": 1784016000000000000
    }
  ]
}
```

Device 하나의 latest Event가 fresh하더라도 그 Device의 모든 resource가 fresh하다고 가정하지
않는다. AI 서비스는 필수 resource 각각의 존재, type, 시각 정렬과 window 충족을 다시 검사한다.

## Local Data 경계

두 Device Service는 같은 node의 고정 AI consumer를 위해 최근 10분·Device/resource별 최대
10,000 sample의 memory cache와 read-only latest/recent API를 제공한다.

- Pod가 재시작하면 cache는 사라진다.
- offline replay나 durable outbox가 아니다.
- 장기 이력은 Core Data API에서 읽는다.
- NetworkPolicy 선언은 존재하지만 현재 Flannel에서 client label 강제는 보안 경계가 아니다.

## MQTT와 ingest gateway

중앙 `edgex-messagebus`는 EdgeX 내부 runtime이다. MQTT-only 장비 또는 명시적 local pub/sub가
필요한 경우에만 별도 broker를 둔다. Serial·I2C·Modbus·OPC-UA 직접 Device Service에는 MQTT가
필수가 아니다.

중앙 ingest gateway는 저장소에 유지되지만 현재 Serial/I2C 정상 Event 경로에는 참여하지
않는다. 과거 edge agent/outbox 설명을 현재 데이터 경로로 사용하지 않는다.

## 영상 경계

RTSP frame은 Core Data로 운반하지 않는다. 요청된 Workflow Pod가 stream을 직접 구독하고,
필요한 경우 상태·분석 결과 metadata만 EdgeX Event로 보낸다.
