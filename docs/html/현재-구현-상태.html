프로토콜 독립형 디바이스 발견·등록 현재 구현 상태

기준일: 2026-07-27 판정 기준: 실제 코드, 테스트, edgex/k8s render “구현”과 “실장비 운영 검증”을 구분한다.

요약

Serial은 PTY 후보 발견부터 승인, 검증 Runtime 재사용, EdgeX Profile/Device idempotent 등록, Core Data 첫 Event 확인까지 자동화된 코드와 fake backend 통합 테스트가 있다. 2026-07-24 실제 Jetson Arduino stable 후보를 운영자가 승인했고 기존 Device Service Runtime을 재사용해 aggregate Device arduino-75035303230351e0d171-57fc03a907의 EVENT_CONFIRMED와 Core Data Event까지 live 확인했다.

I2C는 allowlist identity probe와 mock test까지 구현했고 Raspberry Pi 실장비 active probe는 아직 검증하지 않았다. MQTT는 자기등록 schema parser까지만 구현했으며 subscriber가 없다. Modbus는 네트워크 discovery 없이 운영자가 선언한 고정 개발 endpoint에 한해 공식 EdgeX device-modbus:4.0.2 Runtime, read-only Profile, Modbus TCP simulator와 승인 Saga를 연결했다. 이 경로는 자동 테스트를 통과했지만 아직 live cluster Event를 확인하지 않았으므로 실제 PLC 지원 완료가 아니다. OPC-UA와 ONVIF는 확장 contract와 명시적 not implemented 상태만 있다.

실장비 검증 필요

  • USB 케이블 실제 분리·재연결과 같은 candidate ID 및 Device Service 복구
  • Raspberry Pi Sense HAT의 allowlist identity probe
  • 외부 인증 운영 endpoint
  • 공식 Modbus Controller-owned Runtime의 live 배포, Core Data 첫 Event와 rollback
  • 실제 PLC의 Modbus TCP/RTU register map과 연결·재연결
  • ONVIF/OPC-UA/MQTT 실장비는 구현 후 별도 검증

기존 device-serial-jetson과 센서별 6개 virtual Device의 live telemetry를 신규 aggregate 등록의 완료 증거로 대신 사용하지 않는다. 신규 candidate는 운영자 승인 전 Core Metadata에 추가되지 않는다.

보안·운영 주의

  • Controller base는 ADAPTER_AUTH_MODE=external로 fail-closed한다. 현재 root testbed만

overlays/development/adapter-management에서 development-mock을 적용하며 운영 profile이 아니다.

  • Catalog API는 read-only이며 임의 image 실행 API가 없다.
  • Agent의 /dev, /sys mount는 read-only이나 broad host inventory 권한이다. 신규

protocol active probe 권한은 node별 최소 group/device overlay로 검토한다.

  • Controller SQLite는 1Gi RWO PVC를 사용해 단일 replica 기준이다. 다중 replica HA를

활성화하지 않는다.

  • SQLite PVC를 삭제하면 candidate, 전이 이력, 승인, Saga와 audit를 복구할 수 없다.
  • Service는 ClusterIP 객체와 DNS를 사용하지만 고정 ClusterIP 우회는 없다.
  • EdgeMesh manifest는 수정하지 않았다.
  • 현재 PoC의 /management/* mutation은 browser 관리자 token이나 Authorization

header를 요구하지 않는다. 기능 플래그, allowlist 검증, Idempotency-Key와 내부 HMAC은 유지하지만 이는 운영자 인증이 아니다. 접근이 제한된 개발 테스트베드 경계이며 운영 노출 전 별도 사용자 인증·인가가 필요하다.
