2026년도 2차년도 옥동 PoC 추진계획(안)

이 문서는 보고서 본문용 추진계획이다. 아래 내용은 2차년도 목표이며 현재 구현 완료 상태를 뜻하지 않는다. 세부 데이터 항목, 기술 설계, 장애 시나리오, 화면 목록과 실제 검증 결과는 문서 하단의 별첨 기준 문서에서 관리한다.

현재 테스트베드에서는 HAMi GPU와 CUDA readiness를 사용하는 Server1 observed-only 후보까지 운영한다. 2026-08-18 현재 통계 기준선 후보는 90-run 부하 실험에서 성능 자격이 거부됐다. 이는 10월 엣지·서버 배치 검토의 선행 증거이며 승인 기반 요청 전환 완료를 뜻하지 않는다.

2026-08-25 승인된 선행 구현 범위는 서비스 자원 프로파일과 노드 자원 snapshot을 이용한 신규 단일 replica Deployment 생성까지다. 전용 namespace, immutable image allowlist, exact-node placement와 Pod Ready 확인을 포함하지만 기존 workload migration, offloading, runtime replanning과 자동 장애복구를 완료 기능으로 포함하지 않는다.

Runtime Recommendation은 자원·서비스 지표로 증강/대체 필요성과 후보를 read-only로 추천하고 dwell/cooldown 이력을 남기지만 자동 배포·전환·삭제는 하지 않는다. 별도 승인 Controller의 candidate 생성, SHADOW validation, Lease handoff/rollback과 core Endpoints 전환은 2026-08-26 격리 시험에서 확인했다. production은 Argo CD selector와 EndpointSlice 계약을 유지하므로 traffic 단계가 routing_mode_unsupported로 차단되고, 기존 workload 종료·candidate promotion·자동 정리도 지원하지 않는다.

Jetson 수집·저장을 유지하고 Server1에 추론만 요청하는 LOCAL/REMOTE/LOCAL_FALLBACK도 격리 시험에서 확인했다. 2026-08-28 현재 관련 코드는 테스트를 통과했지만 미커밋·미배포이며, Server1 성능 자격은 rejected이므로 범용 offloading이나 운영 요청 전환 완료가 아니다.

1. 추진 배경

2차년도에는 대규모 혼합 디바이스 제어·관리 플랫폼의 요소기술을 개발하고 프로토타입을 구축한다.

2026년 7월 29일 옥동 현장회의 결과, 신규 장비가 필요한 서비스보다 현재 확보된 PLC·MES·센서 데이터를 활용할 수 있는 서비스를 우선 추진하기로 하였다.

우선 실증 대상은 다음과 같다.

  • 센서·MES 데이터 기반 생산품질 양품·불량 판별
  • 메인·보조 유압펌프 및 모터 이상 감지

두 서비스는 개별 AI 모델 개발에 그치지 않고, 플랫폼의 데이터 수집·서비스 배포·장애복구 기능을 검증하는 대표 PoC 시나리오로 활용한다.

2. 추진 목표

옥동 현장의 PLC·MES·센서 데이터를 엣지 AI 플랫폼과 연계하고, 우선 서비스 2종을 대상으로 다음 기능이 통합된 PoC 프로토타입을 구축한다.

  • 현장 데이터 실시간 수집 및 통합

  • 엣지 디바이스와 서버 간 작업 분산

  • 통신·서비스 장애 시 저장, 재전송 및 복구
