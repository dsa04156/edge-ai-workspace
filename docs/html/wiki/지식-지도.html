  • 운영 모델: 현재 PoC의 목표, 권위 경로, 완료 판단 기준을 요약한다.

  • 상태와 텔레메트리: EdgeX 물리 디바이스 상태·텔레메트리와 KubeEdge 노드·워크로드 상태를 분리한다.
  • 대시보드와 KPI 모델: 디바이스·서비스·노드·KPI를 운영 판단 기준으로 묶는다.
  • 운영 진입점: 실제 데모 실행과 검증 문서로 안내한다.
