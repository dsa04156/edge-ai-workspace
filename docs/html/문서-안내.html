문서 안내

이 문서 사이트는 현재 운영 중인 Edge AI 플랫폼을 이해하고 장비·서비스를 연결하는 데 필요한 문서만 공개한다. 개발 일지, 과거 실험, 구현 계획서는 검색과 탐색에서 제외한다.

문서가 따르는 원칙

  1. 실제 코드, root Kustomize, 테스트와 live read-only 증거를 우선한다.
  2. EdgeX는 물리 디바이스 inventory·schema·상태·telemetry의 권위다.
  3. KubeEdge/Kubernetes는 노드와 workload의 권위다.
  4. 대시보드는 두 권위의 값을 읽고 연결 관계와 판단 근거를 보여준다.
  5. 구현되지 않은 workflow·offloading·자동 제어는 현재 기능처럼 설명하지 않는다.
  6. 비밀번호, token, URL userinfo와 Secret 값은 문서에 기록하지 않는다.

공개 문서와 내부 이력

문서 웹에는 시작하기, 연결 가이드, 운영, 정책·계약, 개발 참고 문서만 게시한다. docs/archive/와 docs/superpowers/는 과거 실험·설계 이력이며 공개 문서 생성과 검색에서 제외한다. 이력 원본은 비교와 재현에 필요하므로 저장소에는 보존한다.

원본 Markdown을 수정한 뒤에는 다음 명령으로 HTML을 다시 만든다.

python3 scripts/build-docs-html.py
python3 -m unittest tests.test_docs_html_search

docs/html/은 생성물이다. 라이브 반영 여부는 Argo CD docs-html, 실행 중 image digest와 Traefik 주소를 따로 확인한다.
