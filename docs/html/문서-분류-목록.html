보관 문서

docs/archive/는 과거 통합 기록, 연구 초안, legacy orchestration 자료다. 보관 문서에는 HTML에서 과거 자료 안내가 표시되며, 현재 기준 문서로 이동하는 링크를 우선한다. 원본은 삭제하지 않고 역사·재현 근거로 보존한다.

  • archive/integration/: 과거 통합·인수인계·MQTT canary 기록
  • archive/legacy-orchestration/: 과거 오케스트레이션·placement·offloading 설명

보관 문서의 내용을 현재 운영 구조로 승격하려면 먼저 프로젝트-범위.md와 저장소-구조.md에 범위·소유권·검증 기준을 추가해야 한다.
