대시보드 어댑터 런타임 관리 구현 계획

실행 기준: 각 작업은 실패 테스트를 먼저 확인하고 최소 구현으로 통과시킨 뒤 관련 회귀 테스트를 실행한다. 기존 EdgeMesh와 KubeEdge Device CRD는 어떤 단계에서도 변경하지 않는다.

목표: 대시보드에서 기존 EdgeX Device Service runtime을 발견·재사용하거나 승인된 template로 KubeEdge node에 배포하고, EdgeX Profile/Device 등록과 첫 Event 검증까지 하나의 operation으로 관리한다.

구조: state-aggregator는 browser-facing BFF와 EdgeX saga를 담당한다. 별도 adapter-controller가 allowlist template와 AdapterRuntime CR을 reconcile하고 Kubernetes write 권한을 독점한다. EdgeX는 물리 Device 권위이며 CR은 workload desired state만 표현한다.

기술: Python 3.12, FastAPI, Pydantic v2, Kubernetes Python client, pytest, Node test runner, Kubernetes CRD/RBAC/Kustomize, Go Device SDK, Playwright.
