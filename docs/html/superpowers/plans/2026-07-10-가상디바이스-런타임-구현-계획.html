가상디바이스 런타임 구현 계획

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Build an executable second-year prototype that reads Serial JSON through a profile-driven adapter, emits normalized virtual-device telemetry to a local MQTT broker, and publishes lifecycle/heartbeat status without implementing AI, KubeEdge, EdgeX, registry, dashboard, or orchestration features.

Architecture: A validated YAML DeviceProfile configures one adapter, one normalizer, and one MQTT output. VirtualDeviceRuntime owns lifecycle, duplicate/stale suppression, status transitions, heartbeat, bounded reconnect backoff, and graceful shutdown; adapter and publisher dependencies are injectable so tests need neither serial hardware nor a broker.

Tech Stack: Python 3.11+, dataclasses, PyYAML, pyserial, paho-mqtt, pytest, Docker.

Global Constraints

  • Keep sensor-collector/serial_mqtt_collector.py and tests/test_serial_mqtt_collector.py unchanged and passing.
  • Publish only fields declared under mapping.properties; never copy the complete raw payload.
  • Keep sourceTimestamp separate from collectedAt and suppress exact duplicates and older comparable timestamps.
  • Runtime support is limited to Serial JSON plus a test-only fake adapter and local MQTT output.
  • Preserve all pre-existing dirty-worktree changes and do not commit unrelated files.
