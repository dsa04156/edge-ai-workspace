로컬 데이터 캐시 v2 구현 계획

For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

Goal: Serial과 Sense HAT Device Service의 최근 데이터 저장을 공통 bounded ring cache로 교체하고 64MiB 슬롯 예산과 운영 관측값을 제공한다.

Architecture: EdgeX SDK와 분리된 edgex/local-data-cache 제네릭 Go module이 series별 링버퍼, 시간·개수·전체 byte 제한과 stats를 소유한다. 각 Device Service는 얇은 타입 adapter, Driver 설정, EdgeX custom metrics와 /api/v3/localdata/stats route만 소유하며 중앙 AsyncValues 흐름은 유지한다.

Tech Stack: Go 1.25 generics, EdgeX Device SDK v4 MetricsManager, Echo custom routes, Kustomize, ko ARM64 image build, pytest/Go race tests

Global Constraints

  • 운영 배포 진입점은 edgex/k8s와 Argo CD Application edgex-telemetry다.
  • 고정 ClusterIP, PodIP와 node IP를 설정하거나 우회 경로로 사용하지 않는다.
  • 캐시 기본값은 10m, series별 10000, Device Service별 sample slot 67108864 bytes다.
  • 기존 latest/recent HTTP status, 정렬, limit과 JSON field는 깨지지 않는다.
  • 물리 디바이스와 Event/Reading 권위는 EdgeX이며 KubeEdge DeviceStatus를 병행 plane으로 추가하지 않는다.
  • SQLite Outbox, offline replay, Redis와 카메라 frame cache는 이번 구현 범위가 아니다.
  • 구현은 main worktree에서 직접 커밋하되 원래 루트 worktree의 사용자 변경은 건드리지 않는다.

func TestCacheRebalancesSeriesWithinByteBudget(t *testing.T) {
    slot := int64(unsafe.Sizeof(Sample[int32]{}))
    cache, err := New[int32](Options{
        MaxAge: time.Hour, MaxSamplesPerSeries: 4, MaxBytes: slot * 4,
    })
    require.NoError(t, err)
    for _, resource := range []string{"a", "b"} {
        for origin := int64(1); origin <= 4; origin++ {
            require.NoError(t, cache.Append("device", resource, Sample[int32]{Origin: origin, ValueType: "Int32", Value: int32(origin)}))
        }
    }
    assert.Equal(t, []int64{3, 4}, origins(cache.Query("device", "a", 0, 10, 10, 10)))
    assert.LessOrEqual(t, cache.Stats().AllocatedBytes, slot*4)
}
