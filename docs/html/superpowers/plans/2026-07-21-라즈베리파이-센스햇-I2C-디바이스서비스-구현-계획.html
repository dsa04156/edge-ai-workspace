Raspberry Pi Sense HAT I2C Device Service 구현 계획

실행 방식: 테스트를 먼저 실패시키고 최소 구현으로 통과시킨 뒤, ARM64 image와 live EdgeX readback까지 단계별로 검증한다.

Goal: etri-dev0003-raspi5의 Sense HAT v1을 MQTT 없이 직접 읽는 EdgeX Device Service를 배포하고 6개 가상 Device를 중앙/로컬 API와 dashboard에서 확인한다.

Architecture: image 내부 RTIMULib Python reader가 /dev/i2c-1을 한 번 읽어 JSON sample을 만들고 Go EdgeX Device SDK driver가 6개 Device Event, Command와 bounded recent cache로 fan-out한다. 중앙 EdgeX와 EdgeMesh는 유지한다.

Tech Stack: Go 1.25, EdgeX Device SDK Go v4.0.2, Python 3/RTIMULib 7.2.1, Kustomize, Argo CD, Docker buildx, ko, pytest/unittest.
