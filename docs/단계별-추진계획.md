# 2026년도 2차년도 옥동 PoC 추진계획(안)

> 이 문서는 보고서 본문용 추진계획이다. 아래 내용은 2차년도 목표이며 현재 구현 완료
> 상태를 뜻하지 않는다. 세부 데이터 항목, 기술 설계, 장애 시나리오, 화면 목록과 실제
> 검증 결과는 문서 하단의 별첨 기준 문서에서 관리한다.

> 현재 테스트베드에서는 HAMi GPU와 CUDA readiness를 사용하는 Server1 observed-only 후보까지
> 운영한다. 이는 10월 엣지·서버 배치 검토의 선행 증거이며 승인 기반 요청 전환 완료를 뜻하지 않는다.

## 1. 추진 배경

2차년도에는 대규모 혼합 디바이스 제어·관리 플랫폼의 요소기술을 개발하고 프로토타입을
구축한다.

2026년 7월 29일 옥동 현장회의 결과, 신규 장비가 필요한 서비스보다 현재 확보된
PLC·MES·센서 데이터를 활용할 수 있는 서비스를 우선 추진하기로 하였다.

우선 실증 대상은 다음과 같다.

- 센서·MES 데이터 기반 생산품질 양품·불량 판별
- 메인·보조 유압펌프 및 모터 이상 감지

두 서비스는 개별 AI 모델 개발에 그치지 않고, 플랫폼의 데이터 수집·서비스 배포·장애복구
기능을 검증하는 대표 PoC 시나리오로 활용한다.

## 2. 추진 목표

옥동 현장의 PLC·MES·센서 데이터를 엣지 AI 플랫폼과 연계하고, 우선 서비스 2종을
대상으로 다음 기능이 통합된 PoC 프로토타입을 구축한다.

- 현장 데이터 실시간 수집 및 통합
- AI 서비스 컨테이너 배포 및 실행
- 엣지 디바이스와 서버 간 작업 분산
- 결과 저장, 조회 및 이상 알림
- 통신·서비스 장애 시 저장, 재전송 및 복구
- 디바이스와 서비스 상태 통합 모니터링

## 3. 주요 추진내용

| 구분 | 주요 내용 |
|---|---|
| 현장 연계 | 디바이스·센서 목록, 데이터 항목, 수집주기 및 연결방식 정의 |
| 데이터 통합 | PLC·MES·센서·품질 데이터의 공통 타임스탬프 및 생산 건 연결 |
| AI 서비스 | 생산품질 판별 및 펌프·모터 이상감지 서비스 컨테이너화 |
| 워크플로우 | 수집 → 전처리 → 추론 → 저장 → 알림으로 이어지는 실행 흐름 구축 |
| 엣지·서버 분산 | 디바이스 자원과 서비스 요구조건에 따른 배치 및 오프로딩 검토 |
| 장애 대응 | 통신 단절 시 로컬 저장·재전송, 서비스 실패 시 재실행·재배포 |
| 합성·Replay 데이터 | 실제 장비 미확보 구간의 데이터 생성, 장애 및 다중 입력 시험 |
| 통합 화면 | 센서 상태, AI 결과, 알림 이력 및 서비스 운영상태 제공 |

안전 모니터링, 화재 감지, 금형번호 OCR 및 2D·3D 스캐너 기반 품질검사는 장비와 데이터가
확보되는 일정에 따라 후속 추진한다.

## 7. 최종 추진 방향

2026년도 2차년도에는 옥동의 PLC·MES·센서 데이터를 기반으로 생산품질 판별과
유압펌프·모터 이상감지 서비스를 우선 구현한다.

이를 통해 데이터 수집, AI 서비스 배포, 엣지·서버 작업 분산, 결과 저장, 알림 및
장애복구 기능이 연결된 대규모 혼합 디바이스 제어·관리 플랫폼 프로토타입을 구축하고
검증한다.
