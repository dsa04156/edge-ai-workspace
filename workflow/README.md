# workflow manifests

Status: Legacy / Reference

이 경로는 현재 PoC 구현 경로가 아니라 과거 workflow/event/scenario manifest 모음으로 남아 있는 자료다.

현재 PoC의 기준 경로는 다음 문서를 우선한다.

- `../docs/scope.md`
- `../docs/repo-structure.md`
- `../AGENTS.md`

처리 규칙:

- 현재 서비스 데모, 디바이스-서비스 연결 구조, 통합 운영 가시화의 요구사항으로 해석하지 않는다.
- dynamic workflow, runtime replanning, placement/offloading, agent-assisted planning을 현재 완성 기능처럼 설명하지 않는다.
- 이 경로를 다시 현재 범위로 승격하려면 먼저 `docs/scope.md`와 `docs/repo-structure.md`를 갱신해 범위 변경을 명시한다.
- 이 README는 삭제/이동 승인이 아니다. 파일 이동 또는 삭제는 별도 정리 작업에서 승인 후 수행한다.
